# Truck Ledger – Vehicle Owner & Driver Management Platform

A mobile-focused platform connecting commercial vehicle owners and drivers for trip management, expense tracking, vehicle-wise budgeting, and financial reporting.

**Available on the Apple App Store:** [Truck Ledger – Lorry Expense](https://apps.apple.com/us/app/truck-ledger-lorry-expense/id6758997208)

## Project Overview

Truck Ledger streamlines day-to-day commercial vehicle operations by providing APIs for trip management, driver expense tracking, vehicle-wise budgets, and financial reporting.

## Key Features

### Trip Management
- Trip creation and lifecycle management.
- Vehicle- and driver-related trip operations.
- APIs to manage trip details and operational status.

### Expense & Financial Management
- Driver expense tracking.
- Vehicle-wise budget management.
- Trip-related expense calculations and financial reporting.
- PDF generation for expense reports and summaries using Puppeteer.

### Automated Workflows
- Scheduled background processes using Node-Cron.
- Automated reminders and time-based workflows.
- Push notification integration for iOS and Android.

### Authentication & API Development
- Authentication and request validation.
- Role-based access for vehicle owners and drivers.
- REST API development and documentation using Swagger/OpenAPI.
- Database query optimization for trip, vehicle, and expense operations.

## Architecture Highlights

- **Trip Lifecycle Management:** Backend APIs support trip creation and ongoing trip operations.
- **Expense Processing:** Tracks driver expenses and vehicle-wise budgets for financial reporting.
- **PDF Reporting:** Uses Puppeteer to generate downloadable expense and report documents.
- **Scheduled Automation:** Uses Node-Cron to run time-based workflows and reminders.
- **Mobile Integration:** Provides REST APIs and push notification support for mobile application workflows.
- **Performance Optimization:** Improves database queries and API response performance for trip, vehicle, and expense-related operations.
- **Access Control:** Supports separate owner and driver workflows through authentication and role-based authorization.
